# Jiao_Reader 快速上手

## 1. 安装阅读器

从项目的 GitHub Releases 页面下载，或接收同学发来的 `Jiao_Reader-Setup-0.3.4.exe`，按向导选择安装位置，完成后从桌面或开始菜单打开。安装包包含软件所需的运行环境，不需要 Node.js 或 Python。Windows 10 / 11 x64 可用。GitHub 自动提供的 `Source code` 是源码，不是安装程序。

从旧版升级时，先关闭阅读器，再运行新版 Setup，保持原安装目录即可覆盖升级，不必先卸载。最近阅读、优先级、已保存笔记和模型选择保留。软件没有自动更新功能；若使用便携版，应替换完整程序目录，Setup 不会更新其他位置的便携版。

本次应用和安装包版本为 `0.3.4`；沿用的 Electron 启动程序在 Windows `.exe` 文件属性中可能仍显示 `0.3.1`。

当前安装包没有代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。请先核对发送者及文件来源，无需关闭系统防护。

点击“打开 PDF”即可阅读。用滚轮上下移动，顶部页码随阅读位置变化；输入页码可以跳转，`+` / `−` 调整显示大小，“适合宽度”让页面适应窗口。

最近阅读列表会保留通过“打开 PDF”打开的文献。点击条目旁的删除按钮可移除一条记录，点击“清空”可移除全部记录；这些操作只清理列表，不会删除磁盘上的 PDF，也不会关闭当前文献。

拖选文字时，行间空白、页边距和双栏正文的选取更稳定。识别为双栏的正文会将一次拖选限制在起始栏；另一栏请重新划选。复杂版式仍应核对右侧显示的原文，再使用译文。

## 2. 设置最近阅读的优先级

右键最近阅读的条目，菜单只有两项：

- **优先级 +1**：每次增加一级，条目角标显示当前优先级。
- **优先级清零**：将该条目的优先级恢复为 0。

列表先按优先级从高到低排序；优先级相同时，再按最近阅读时间从新到旧排序。优先级保存在本机，重启后仍有效。删除或清空最近阅读不会删除文献已经保存的标签与笔记。

## 3. 给选文添加标签和笔记

这项功能不需要 Ollama，也不需要先完成翻译。

1. 在 PDF 正文中划选文字，右下角“本次阅读”会出现包含原文和页码的记录。
2. 右键该记录，选择“添加标签”或“写评论 / 笔记”。右键“本次阅读”区域的空白处，会使用最近一次选文。
3. 在弹窗中用逗号分隔标签，填写评论、笔记或注释，然后点击“保存”。点击“取消”或按 Esc 会放弃尚未保存的修改。
4. 点击顶部文献标题右侧、页码左侧的“标签与笔记”，查看本篇文献的标注列表。列表按最近更新时间排序，可点击“第 n 页”跳回原页，也可编辑或删除。

标签可选择麦穗黄、鼠尾草绿、雾蓝、淡紫、杏橙或柔珊瑚六种荧光笔色。保存后标签与 PDF 选文同时着色，多标签选文使用第一个标签的颜色；仅评论也能选择标记色。同篇文献中，同名标签改色会同步相关选文，各段评论仍各自保留。

列表顶部的标签入口按 tag 汇总相关选文与评论，点击“全部”恢复完整列表。新标注的位置随页码保存，缩放和重启后恢复高亮；旧版标注只在选文能被唯一匹配时显示高亮。颜色与笔记只保存在阅读器中。

每条标注最多引用 12000 字原文，包含 20 个标签（每个最多 50 字）和 6000 字笔记。原文引用与页码一同保存，便于重新找到相关段落。

标签和笔记独立保存在本机，关闭或重启阅读器后仍可查看。内容完全相同的 PDF 即使复制或重命名，也会关联原有标注；内容不同的同名 PDF 分开保存。笔记不会写入或修改 PDF。

“本次阅读”的选文和翻译历史仅在当前打开文献期间暂存，切换文献或重启会清空。已保存的标签与笔记不随暂存历史清空。

## 4. 准备翻译模型

如果只阅读 PDF，可以跳过这一步。需要本地翻译时：

1. 从 [Ollama 官网](https://ollama.com/download/windows) 安装 Windows 版，安装后启动 Ollama。
2. 打开 PowerShell，用 Ollama 下载模型，例如：

   ```powershell
   ollama pull qwen3:4b-instruct
   ```

3. 下载完成后，可以用以下命令检查已有模型：

   ```powershell
   ollama list
   ```

4. 回到 Jiao_Reader，刷新模型列表，选择本机已有模型。
5. 在论文正文划选一段文字，选区附近会出现翻译气泡，完成后直接查看或复制译文；右侧面板也会同步保留原文与译文。

模型下载需要联网，使用已下载的本地模型翻译可离线进行。第一次翻译或更换模型后可能稍慢，因为 Ollama 需要加载模型。模型越大，对内存和显存的需求通常越高。

Jiao_Reader 的模型面板只选择已经在 Ollama 中准备好的模型。它不会下载模型，也不能直接导入 GGUF 文件；模型安装或导入需要使用 Ollama 命令完成。

## 遇到问题

| 面板现象 | 处理方法 |
| --- | --- |
| 未检测到 Ollama | 安装 Ollama；如果安装在自定义目录，确保已启动服务后再刷新 |
| 检测到安装但无法连接 | 点击“启动 Ollama”，或打开 Ollama；也可以使用 `ollama serve` |
| 已连接，但模型列表为空 | 用 `ollama pull 模型名` 准备本地模型，完成后刷新 |
| 原来选择的模型不可用 | 重新刷新并选择仍在本机的模型 |
| PDF 无法选择文字 | 可能是扫描件，需要先对 PDF 做 OCR |
| 翻译很慢或提示内存不足 | 等待首次加载，或在 Ollama 准备更小模型后切换 |

卸载阅读器：在 Windows“设置 → 应用 → 已安装的应用”中找到 Jiao_Reader 并卸载。Ollama 与模型由 Ollama 管理；卸载阅读器不会卸载 Ollama 或删除模型。
